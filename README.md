📌 Project Overview

The SWYNEX Automated Excel Report Generator is a Python-based automation application designed to simplify business sales reporting and data analysis.

The system automates the complete reporting workflow, including sample sales data generation, data processing, sales analysis, Excel report creation, interactive chart generation, and professional PDF report generation.

It reduces repetitive manual reporting tasks and organizes business data into meaningful reports and visual insights.

🎯 Project Objectives

- Automate repetitive Excel reporting tasks.
- Process and organize sales datasets using Python.
- Analyze sales performance across different categories.
- Generate professional Excel reports automatically.
- Create visual sales analytics charts.
- Generate PDF reports for business documentation.
- Improve reporting efficiency and consistency.

✨ Key Features

1. Automated Data Generation

- Generates sample sales datasets.
- Creates structured Excel data.
- Calculates total sales values.

2. Data Processing

- Loads and processes sales datasets.
- Handles date conversion.
- Prepares cleaned data for analysis.

3. Sales Analysis

- Calculates total revenue.
- Analyzes product-wise sales.
- Analyzes category-wise sales.
- Analyzes region-wise sales.
- Performs monthly sales analysis.

4. Automated Excel Reporting

- Generates Excel reports automatically.
- Organizes sales analysis results.
- Stores processed reporting data.

5. Interactive Data Visualization

Generates HTML-based sales charts:

- Product-wise Sales Chart
- Category-wise Sales Chart
- Region-wise Sales Chart
- Monthly Sales Chart

6. Professional PDF Report Generation

- Generates automated PDF reports.
- Includes executive summaries.
- Displays sales performance tables.
- Provides business insights.
- Adds page numbers and report details.

7. Integrated Execution

Runs the complete reporting workflow through a centralized Python application.

⚙️ Installation and Setup

Step 1: Clone the Repository

git clone https://github.com/GANESH2119/SWYNEX-Python-Automation-Tool.git

Step 2: Navigate to Project Directory

cd SWYNEX-Python-Automation-Tool

Step 3: Create Virtual Environment

python -m venv venv

Step 4: Activate Virtual Environment

For Windows:

venv\Scripts\activate

Step 5: Install Dependencies

pip install -r requirements.txt

▶️ How to Run

Execute the main application:

python main.py

The application runs the reporting modules sequentially and generates the required output files.
